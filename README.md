# Atlas of Rooms

**Live:** [https://atlas-of-rooms-the-original-enigma-studios.vercel.app](https://atlas-of-rooms-the-original-enigma-studios.vercel.app)

A searchable, plain-language reference of 129 mental health conditions grouped by category, with ICD-10 codes. Data lives in `data.json`; the site is a single static `index.html`.

For learning only, not a diagnostic tool or medical advice.
